# Foldseek baseline

This folder records the exact Foldseek version and exhaustive command used for the comparison.

Version/commit: 463739e0014a1549a527de589102cde98f802f37

Primary command pattern:

bash Code/Foldseek/run_foldseek.sh /path/to/foldseek

The submitted result table is Results/Foldseek/Full_Heldout/foldseek_exhaustive_raw.tsv. The primary score is the maximum Foldseek probability across the two search directions. All 24,520 benchmark pairs are represented.

Install Foldseek separately and use the pinned commit shown above.
